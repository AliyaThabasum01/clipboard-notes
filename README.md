# 📝 Clipboard Notes

A simple Python CLI application for saving and viewing quick notes.

## Features

- Add notes
- View saved notes
- Store notes locally
- Simple menu interface
- No external dependencies

## Run

```bash
python main.py
```

## Example

```text
1. Add note
2. View notes
3. Exit

Choose: 1
Enter note: Build a new project

✅ Note saved.
```

## Built With

- Python
- File Handling
